# songscope

[日本語](README.md) | [English](README.en.md)

AIエージェントは音を聴けません。それでも、生成した曲が狙いどおりの形になっているかは確かめたい。songscopeは、曲を**絵と数字**に変えて、耳を使わずに検品するための小さな道具集です。音楽生成AIで作ったテイクを比べたり、選んだりする場面を想定しています。

どの道具も「良い曲かどうか」は判定しません。測るのは「サビで上がっているか」「歌詞どおりに歌っているか」「声が参照に寄ったか」といった、**狙った形になっているか**です。

| 道具 | 入力 | 出すもの |
|---|---|---|
| `songscope.py` | 曲（2mix） | メルスペクトログラム・旋律・音量を重ねたPNGと、音域・最高音の位置・サビの張り・明るさのJSON |
| `melody_read.py` | 分離したボーカルのステム | 歌っている区間ごとの中央音・最高音、全体の音域 |
| `lyrics_adherence.py` | 歌詞ファイルと音源（複数可） | 歌詞の網羅率・順序の逆行数・落ちた行 |
| `voice_sim.py` | 参照音声と候補（複数可） | 声の帯域のスペクトル類似度とF0中央値 |

## 動作要件

- Python 3.9以降
- `pip install -r requirements.txt`（numpy, scipy, soundfile, librosa, matplotlib, faster-whisper）
- `melody_read.py` は ffmpeg を使います
- `lyrics_adherence.py` は初回に faster-whisper のモデルを取得します（既定は `small`、CPUで動きます）

## 使い方

### songscope.py — 曲を絵と数字にする

```sh
python3 songscope.py song.mp3 -o songscope-out
```

`songscope-out/song.png` と `songscope-out/song.json` ができます。PNGは上から、メルスペクトログラムに旋律（水色）を重ねた図、音量、音高の推移です。音高の図では、サビの「張り」の区間が黄色く塗られます。

JSONの主な項目:

- `音域_半音`、`最高音`、`最高音の時刻_秒`、`中央音`
- `張りの回数`、`いちばん高い張り`、`最高音は後半3割か`、`張りと地の差_半音`
- `強い所と弱い所の差_dB`、`強い所の明るさ_Hz` / `弱い所の明るさ_Hz`、高域比

**サビは音量では見つかりません。** マスタリングで潰れた曲は音量が真っ平らになるからです。そこで旋律の高止まりを使います。中央音より4半音以上高い所に0.4秒以上留まる区間を「張り」とみなし、サビと山場の代わりにします。

旋律を追う帯は既定で女声向けの E3〜D6 です。下限を低くしすぎると、pyinがベースを拾って中央音がベースの高さになります。男声なら `--fmin C2 --fmax G5` のように広げてください。

### melody_read.py — ボーカルのステムから旋律を読む

```sh
python3 melody_read.py vocals.wav [--gap 1.2]
```

2mixでは伴奏に引っぱられて旋律を追えないので、Lead Vocalのステムだけを渡します。無音（既定1.2秒以上）で歌の区間を区切り、区間ごとの中央音と最高音を並べます。サビの区間の最高音がAメロの区間より上になっているかを確かめるのに使います。

```
vocals.wav  尺 235.9s  歌の区間 5本
 #      入り      尺         中央         最高
 1    0.4s  13.8s    492Hz   B4    672Hz   E5
 2   17.3s  21.7s    375Hz  F#4    648Hz   E5
 ...
```

### lyrics_adherence.py — 歌詞どおりに歌っているか

```sh
python3 lyrics_adherence.py lyrics.txt take1.mp3 take2.mp3 [--model small] [--threshold 0.45] [--language ja]
```

faster-whisperで書き起こし、歌詞の各行が出ているかを文字bigramのDice係数で判定します。歌詞ファイルは1行1フレーズです。`[Verse]` のような記号だけの行と、5文字未満の行は無視します。

```
file                           網羅率    逆行  落ちた行
take1.mp3                        82%     0  ...
take2.mp3                        48%     0  きみのなまえをよんだ / ...
```

- **網羅率**: 書き起こしのどこかに出た歌詞行の割合
- **逆行**: 出てきた順が歌詞の順と逆になった回数（歌詞に1回しか出ない行だけで数える）

日本語の歌の書き起こしは誤字が多いので、しきい値は緩めにしています。絶対値ではなく、**同じ歌詞・同じしきい値でテイクどうしを比べる**ために使ってください。採点が対応する文字は、ひらがな・カタカナ・漢字です。

### voice_sim.py — 声が参照に寄ったか

```sh
python3 voice_sim.py reference.wav candidate1.wav candidate2.wav
```

200〜4000Hzの長時間平均スペクトルのコサイン類似度と、F0の中央値を出します。伴奏が違うとスペクトルが伴奏に引っぱられます。根拠にするのは、同じ編曲・同じ条件で参照ありとなしを並べたときの差だけにしてください。

## 制約

- 測れるのは形だけです。良い曲かどうか、聴いて心地よいかは判定しません。
- 和音の多い伴奏や強いエフェクトがあると、旋律の推定は外れやすくなります。
- 出力の項目名と表示は日本語です。

## 検査

```sh
python3 -m unittest discover -s tests
```

合成した「Aメロ→無音→サビ」の音で、`songscope.py`、`melody_read.py`、`voice_sim.py` を通しで動かします。サビが上がったことを数字で拾えるかを確かめます。`lyrics_adherence.py` はモデルを使わず、採点の部分だけを検査します。
